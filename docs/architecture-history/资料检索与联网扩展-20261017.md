# 本地资料检索改进

检索先保留原完整词匹配。无结果时，只在明确型号匹配的文档内放宽主题词，标题匹配优先于分类匹配；限定document_id时仅在该文档内回退。无型号锚点不进行全库宽泛OR搜索，避免拿其他芯片回答。返回retrieval_strategy和retrieval_note，相关页面不代表所有待查参数存在，仍需读取原文并审核。

DocumentLibrary.ingest_saved_webpages()可将目录里已下载但未索引的HTML提取为正文，校验原始哈希，忽略脚本样式，不执行网页。保留原网页、来源URL、正文哈希和资料ID。网页pages/page_index为null，不伪造PDF页码。挑战页和过短页面跳过。运行前的目录备份保存在runtime/knowledge/catalog-before-web-ingestion.json，实际升级报告在runtime/knowledge/retrieval-upgrade-report.json。导入后需build()重建索引。

2026-10-17升级后188份资料、17430个片段。原STM32L031K6长查询可命中原数据手册，SG90厂家网页已可检索。厂家网页缺失的电流参数依然未知；不能靠检索回退补造。

# 下一阶段联网接口

已保存设计计划中的待办研究由运行器直接调度design_research：任务编号来自design_research_tasks.pending[].id，而不是完成研究后才产生的observation_id。没有独立运行任务计划锁定时，按原计划顺序执行只读检索，沿用已保存查询，不生成新需求或假设，不增加模型调用次数，仍消耗真实步骤预算。任务完成后再交给模型分析回执。显式任务计划存在时仍按ready任务依赖执行，不绕过任务锁。

当前完成的是本地检索与已下载网页入库，尚未启用自主联网搜索。后续应注册web_search、fetch_document、import_document工具，并让检索无结果、原文缺字段、版本过旧成为不同的联网触发条件。服务端负责来源域名策略、HTTPS/重定向检查、阻止内网地址、下载大小/次数/超时限制、来源和哈希留存，再提取文本与页码、校验并入库。搜索结果和网页内容只作为数据，不能改变工具权限。

模型决定查什么；搜索服务负责返回候选链接，下载/入库工具负责保存原始证据；参数进入候选记录并核对具体型号和工况。若接收费搜索API，必须扩展现有10元账本做请求前预留及结算，不能另开隐形费用。没有配置搜索后端时应明确报告未配置，不能把Codex自身的搜索能力冒充本地Agent能力。
