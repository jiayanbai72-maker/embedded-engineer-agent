# 本地运行协议整理

本次整理把模型输出适配集中到 `decision_protocol.py`，把重复工作检查集中到 `runtime_policy.py`。

普通动作可以只提供 action、arguments、reason。程序补充记录所需的 expected；只有当前恰好有一个同动作的可执行任务时，才补充 task_id。多个候选任务仍须明确选择。工程参数、证据编号、权限和用户确认继续经过原校验。

简化任务计划可提供 goal、reason 和 tasks（action、title）。程序生成内部任务编号和默认顺序依赖；构建、测试等任务的默认完成条件要求工具真实返回 passed。显式提供的条件仍由原计划校验器检查。

模型上下文新增 runtime_frame，集中列出当前可执行队列、真实观察编号、回执编号、最近错误和资料不足时的退出方向。研究任务编号、观察编号与回执编号保持区分。

相同输入和相关状态下，资料搜索、原文读取、参数读取、设计评估、功耗估算若已有执行回执，会暂停重复执行。索引、原文或相关参数与方案改变后可重新执行。此保护仅覆盖这些动作和当前运行记录，不是跨所有轮次的全局去重。

暂停结果新增 reason_code、reason_label，分别标识步骤用完、模型调用次数用完、连续校验失败、费用保护、等待确认和重复工作。步骤额度与每日费用额度独立。

验证：112 项离线测试通过，2 项可选环境测试跳过。没有调用付费模型，也没有自动开始推进。真实 DeepSeek 连续运行仍须另行验证；自主联网检索尚未接入。
