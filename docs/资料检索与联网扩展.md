# 本地资料不足时的联网补充闭环

更新：2026-10-18。已接入工作台及智能体受控工具；不是使用 Codex 自身搜索工具来冒充应用能力。

## 当前流程

1. 本地库先执行型号锚定、中英文主题词和原文检索。命中片段不等于参数充分或已审核。
2. 本地未命中时，`research_documents {query}` 执行原厂来源检索；已有资料但确实缺字段时提供 `missing_field`。
3. 默认使用公开 Bing RSS 搜索入口，不使用收费搜索 API。按用户允许域名筛选结果，每次最多保留3条，自动导入前2条。
4. 公开搜索可能返回不相关结果；没有允许的原厂链接时，只能把本地目录中型号匹配的已知原厂URL作为明确标注的后备来源。它们不被冒充为新的搜索命中。
5. 已知原厂链接可直接 `fetch_document {url}`；不依赖搜索引擎。原网页返回的真实PDF链接可在 `read_document_page` 的 `related_pdf_urls` 中获得，模型可继续导入合适手册。
6. 保存原始文件、来源URL、下载时间、SHA-256、提取正文和资料ID，再原子更新目录与重建索引。入库失败恢复旧目录，不宣称成功。相同文件哈希复用现有资料。
7. PDF在独立进程提取物理页码，网页页码为null，不伪造PDF页码。扫描件、加密PDF、提取器缺失等返回明确失败。
8. 回查本地库后由Agent自动读取原文，必要时跟进页面中的真实技术PDF链接；最多尝试三种查询。导入本身不产生参数审核记录。Agent通过 `record_parameter` 提交原文引用、型号、参数值、单位与工况：程序先验证引用、型号、数值和单位，再由独立模型调用核对参数语义、范围和条件。通过才登记带来源哈希的参数记录，相同记录复用。模型核对不等于专家认证或实物验证。

## 停止与继续

- 未配置、网络不可用、无允许来源、超限、正文不足或索引失败均记录具体状态。
- 同项目相同查询和URL默认复用已保存结果，包括失败，不重复联网。用户可在界面明确允许重试失败项，但不重置已消耗次数。
- 每项目最多10次搜索、10次下载；每次下载最多8MB，重定向最多3次，连接/读取有超时，PDF提取最多25秒及1000页。
- 停止相关取证任务后继续不依赖该证据的步骤。非关键项可明确标注假设；电气安全、兼容性、真实报价等不可猜测通过。
- 没有新资料时，不重复相同检索和模型分析。网络操作不调用模型；模型决定查什么或分析结果仍沿用原每日10元模型预算。

## 工作台入口

“资料与证据” → “Agent 自主资料补充”。Agent自行检索、下载、读取和核对，不要求用户搜索、下载PDF或填写审核表。手动检索和人工核对折叠为可选高级功能。原厂域名补充已启用，用户可停用；保存设置本身不会发出网络请求。证据不足时只保留相应缺口，继续不依赖该证据的任务，不重复索取人工辅助。语义核对使用已配置模型，计入每日10元限制；预算暂停继续生效。

## 网络与来源边界

只接受HTTPS无凭据URL及443端口。所有重定向重新校验来源域名与DNS公开IP；TLS连接固定到已验证IP，仍校验原域名证书，防止校验后重新解析到内网。禁止回环、链路本地、内网、非公开地址及超限响应；不执行网页脚本或PDF附件，不绕过登录或挑战页，不下载可执行程序。

搜索词应只有型号和资料关键词，不提交密钥、源码或完整项目描述。来源域名列表由用户设置，Agent不能修改。域名允许不等于内容参数正确，网页和检索内容仍是不可信数据，不能改变工具权限。

## 实际验证及局限

离线用例覆盖域名/内网/重定向限制、查询去重、重试限额、下载入库、失败回滚、网页引用、真实PDF页码和参数未审核状态。

真实网络验证：公开RSS入口可响应，但本轮STM32查询未筛出有效原厂搜索链接；没有把不相关结果入库。ST原厂STM32L031K6产品页已成功下载入库，并验证该产品页真实数据手册链接可下载，复用已有126页手册记录且可按物理页码读取。搜索后端可用性及覆盖率不作保证；提供原厂URL始终是独立的后备入口。

主要实现：`online_research.py`、`extract_online_pdf.py`、`web_documents.py`、`library.py`；工具与编排在 `service.py`、`control.py`、`design.py` 中接入。历史在 `runtime/web-research/`，原文在 `knowledge/official/online/`，项目交付归档可包含 `online-research.json`。
